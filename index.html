Definition of a Vector Space

A Vector Space (or linear space) over a Field $F$ (such as $\mathbb{R}$) is a set $V$ equipped with two binary operations called vector addition ($+$) and scalar multiplication ($\cdot$) satisfying the 10 fundamental axioms below:

$$\text{Vector Space: } (V, +, \cdot, F)$$ $$\text{Vector Addition: } + : V \times V \to V \quad \mid \quad \text{Scalar Multiplication: } \cdot : F \times V \to V$$

1. The Set ($V$)

A non-empty set of objects called vectors (tuples, functions, matrices, polynomials).

2. Scalar Field ($F$)

A set of scalars (such as $\mathbb{R}$) for scaling elements in $V$.

3. Addition ($+$)

Combines any two vectors $\mathbf{u}, \mathbf{v} \in V$ to produce $\mathbf{u} + \mathbf{v} \in V$.

4. Scalar Mult ($\cdot$)

Scales a vector $\mathbf{u} \in V$ by a scalar $\alpha \in F$ to produce $\alpha \mathbf{u} \in V$.
